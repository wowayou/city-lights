## 审查范围与取舍

阅读了生成器、通电／悬空判定、旋转／锁定／提示／撤销、回放、每日／关卡／评分、存档、主循环与输入、Canvas 布局、双语文案及现有测试。核心接线规则和参考解回放在现有测试及真实点击中正常；本次不改生成算法、日期种子、过关条件、提示代价或存档前缀，避免让既有题目与记录失效。

优先处理已复现的「看不全／点不准」「中断后状态不可信」「输入做错动作」三类阻碍，而非增加玩法或装饰。以下为修改前实测，不是推测：

| 优先项 | 复现与影响 | 验收边界 |
|---|---|---|
| 小屏／横屏布局 | 568×320 首页标题上缘为 −86px，玩法说明在 361px 以下，页面禁止滚动；每日棋盘单格仅 17px。844×390 结算时棋盘单格约 10px，并被结算卡覆盖。 | 首页、结算、回放在窄屏／横屏均可达；横屏不继续把棋盘挤在上下控件之间；板面与交互面板不重叠；双语不横向溢出；切换方向不改变局面。 |
| 续玩与计时 | 旋转后撤销到 0 步、返回主页再进入，等待 1.3 秒计时仍为 1500ms。模拟写入配额失败后，2 步返回主页变回旧存档的 1 步，且无提示。 | 首次旋转前不计时，首次旋转／提示后计时独立于步数，重来／撤销／刷新保持该语义；后台不计时，前台卡帧不漏时；保存失败明确告知限制，同一页面会话内仍能续玩／保存成绩；正常存储与旧存档兼容。 |
| 输入可靠性 | 方向键选格，再聚焦「撤销」按回车，0 步变成 1 步（旋转了棋盘）。按住棋盘、Esc 回主页并重新开局，旧长按计时器会锁住新局的一格。 | 按钮／滑条保留原生键盘操作，棋盘键盘操作有明确焦点；拖出／取消／失焦／切屏／调整视口终止手势；多指不互相触发长按；正常点击、长按、右键、撤销和回放仍正常。 |
